# 유튜브 자막 번역 도구

## User-visible outcomes

- 유튜브 링크를 입력하면, 영상에 영어 자막이 있는 경우 영상 재생 화면과 함께 왼쪽엔 영어 자막 전체 텍스트, 오른쪽엔 한국어 번역 전체 텍스트가 나란히 보인다.
- 영어 자막이 없는 링크를 입력하면, 처리할 수 없다는 안내를 보여주고 아무 것도 저장하지 않는다.
- 처리를 마친 영상은 링크·영어 자막·한국어 자막이 하나의 레코드로 저장되어 목록에서 다시 찾아볼 수 있다.
- 이미 처리한 적 있는 링크를 다시 입력하면 재번역 없이 저장된 결과를 바로 보여준다.
- 번역 기능은 별도 계정 등록이나 결제 없이 동작한다.

## Approved scope

- 유튜브 링크 입력 → 영어 자막 추출 → 한국어 번역 → 영상 재생 화면 + 좌(영어)/우(한국어) 자막 전체 텍스트 표시.
- 처리 결과를 링크·영어 자막·한국어 자막 단위의 레코드로 저장하고, 저장된 레코드 목록을 다시 열람하는 화면.
- 본인 1인이 로컬에서 쓰는 개인용 도구.

## Observable acceptance criteria

- 영어 자막이 있는 유튜브 링크 입력 시: 영상 재생 화면, 좌측 영어 자막 전체 텍스트, 우측 한국어 번역 전체 텍스트가 모두 한 화면에 보인다.
- 영어 자막이 없는 유튜브 링크 입력 시: "처리할 수 없다"는 안내만 보이고, 목록에는 아무 항목도 추가되지 않는다.
- 처리 완료 후 목록 화면에 진입하면, 방금 처리한 링크가 항목으로 보이고 클릭하면 저장된 영어 자막·한국어 자막을 다시 볼 수 있다.
- 목록에 이미 있는 링크를 다시 입력하면, 번역 요청 없이 곧바로 저장된 결과가 보인다.
- 번역 과정에서 API 키 입력이나 결제 수단 등록을 요구하지 않는다.

## Settled constraints and rationale

- **번역은 별도 계정/비용 없이 쓸 수 있는 방식으로 한정한다.** 사용자가 명시적으로 확정. PRODUCT.md의 번역 품질 기준("이해할 수 있는 수준이면 충분")과 개인용 1인 도구라는 성격상 유료 API 설정 부담을 감수할 이유가 적기 때문.
- **영어 자막이 있는 영어 영상만 대상으로 한다.** PRODUCT.md에서 확정된 경계. 자막이 없으면 처리하지 않는다.
- **자막은 재생 동기화 없이 전체 텍스트로 나열한다.** PRODUCT.md에서 확정.
- **자막 추출은 `yt-dlp`를 서버 서브프로세스로 호출해 수행하며, 이 앱을 실행하는 컴퓨터에 `yt-dlp`가 설치되어 있어야 한다.** 구현 중 발견해 사용자가 확정. 유튜브가 자막 API 요청에 봇 방지 토큰(PO Token)을 요구하기 시작해, Node.js에서 직접 자막 주소를 호출하거나(빈 응답 확인) 잘 알려진 라이브러리(`youtubei.js`, 여러 클라이언트 모드)를 써도 자막을 가져올 수 없음을 실제로 재현해 확인했다. `yt-dlp`는 이 우회 로직을 자체적으로 유지하고 있어 실제 테스트에서 정상 동작을 확인했다. `yt-dlp` 설치는 무료·계정 불필요이지만, "설치"라는 새로운 실행 전제가 생긴다.

## Assumptions

- 자동 생성 자막을 포함해 영어 자막 트랙이 하나라도 있으면 처리 대상으로 본다. 수동 자막과 자동 생성 자막이 모두 있으면 수동 자막을 우선 사용한다. (근거 없이 채택했을 때 감수하는 위험: 자동 생성 자막의 품질이 낮아 번역 결과도 함께 떨어질 수 있음 — 실제 사용해보고 문제되면 쉽게 조정 가능)
- 영상 재생은 유튜브 자체 플레이어(임베드)를 사용한다.
- 처리 결과 레코드는 서버 측에 보관해 브라우저나 기기와 무관하게 다시 열람할 수 있게 한다.
- 이미 저장된 링크를 다시 입력하면 재번역하지 않고 기존 레코드를 재사용한다.

## Off-limits and why

- 영어가 아닌 원어 자막 표시, 다국어 지원 — PRODUCT.md 경계에서 "영어 영상만"으로 확정했으므로 이번 범위 밖.
- 재생 시점에 맞춘 자막 동기화(하이라이트·자동 스크롤) — PRODUCT.md에서 "전체 텍스트 나열"로 확정했으므로 이번 범위 밖.
- 로그인·다중 사용자 지원 — 본인 1인이 쓰는 개인용 도구이므로 범위 밖.
- 유료 번역 API 연동 — 별도 계정/비용 없는 방식으로 확정했으므로 범위 밖.

## Deferred points

- 저장된 목록을 정렬하거나 검색하는 구체적인 방식 — PRODUCT.md에서도 Unknown으로 남김. 항목이 많지 않은 초기 단계에서는 목록 나열만으로 시작하고, 필요해지면 다시 다룬다.

## Remaining risks

- 별도 계정/비용 없이 쓰는 번역 방식은 요청 빈도 제한이나 일일 할당량 제한이 있어, 긴 자막을 번역할 때 실패하거나 느려질 수 있다. 완화책으로 Google 비공식 엔드포인트 → MyMemory API 순서의 폴백 체인을 적용했다(하나가 막히면 다음 것을 자동 시도). 다만 짧은 시간에 같은 IP로 대량 테스트를 반복하면 두 제공자가 모두 동시에 막힐 수 있음을 실제로 확인했다(2026-08-29, `docs/follow-ups/translate-provider-rate-limit.md`) — 이 경우 청크 단위 재시도 간격을 두거나 세 번째 무료 제공자를 추가하는 것이 다음 완화책이 될 수 있다.
- 같은 날, 서버측 API 호출 대신 Google 공식 "웹사이트 번역기" 위젯을 클라이언트에 직접 embed해 rate limit 문제를 우회하는 방안을 시도했으나 동작하지 않았다(`docs/follow-ups/google-translate-widget-embed-failed.md`). 현재는 서버측 폴백 체인 방식을 유지한다.
- 자동 생성 자막을 포함하기로 한 가정이 실제로는 번역 품질을 크게 떨어뜨릴 경우, 자막 소스 선택 기준을 다시 조정해야 할 수 있다.
- `yt-dlp`가 설치되어 있지 않은 환경에서는 자막 추출 자체가 동작하지 않는다. 설치 여부를 사전에 확인하고 안내하는 방식이 필요할 수 있다.
- `yt-dlp`가 사용하는 유튜브 우회 방식은 유튜브 쪽 변경에 따라 다시 깨질 수 있다(외부 도구의 유지보수에 의존).
